# Loyce Dairies Platform

A Progressive Web Application for managing dairy product ordering,
payments, inventory and deliveries in Mbarara District, Uganda.

## Project Objectives

- Provide customers with an online dairy product catalogue.
- Support household and business orders.
- Manage inventory and product variants.
- Support scheduled and on-demand deliveries.
- Integrate Uganda-appropriate payment methods.
- Provide administrative and delivery management interfaces.

## Technology Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM
- Neon

## Project Structure

- `client/` – Customer and administrative frontend.
- `server/` – Backend API and business logic.
- `docs/` – Project requirements and architecture documentation.
